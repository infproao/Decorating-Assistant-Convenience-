# 省心 · 装修全能实施顾问（v1.3.0）

一个**平台无关**的装修专家资料包：根目录 `SKILL.md` 是唯一入口，`references/` 是按需读取的知识库与操作手册。不含任何平台专属清单、注册脚本或私有路径，换到哪家 AI 都能直接跑。

## 支持哪些平台

| 平台类型 | 怎么用 |
|---|---|
| 支持 skill / 技能目录机制的 AI（Claude Skills 一类） | 把整个文件夹放进技能目录，入口就是 `SKILL.md`；描述里的触发词会命中「装修」「报价单审核」「效果图」等提问 |
| 支持自定义指令 / 系统提示词的大模型（豆包、ChatGPT、Kimi、通义、文心等） | 用同目录的 `装修全能实施顾问_最终版_单文件.md` 整份粘贴；或把 `SKILL.md` 贴进指令框、`references/` 上传为知识库 |
| 有「知识库 / 文件上传」能力的智能体搭建平台 | `SKILL.md` 正文作角色指令，`references/` 下 11 个 md 全量上传为知识库文件（建议同时开联网，价格与补贴更准） |
| 只想当资料查阅 | 直接读 `references/` 下的文件，不需要任何 AI 配置 |

> 三种形态内容同源同版本：`SKILL.md` + `references/`（分层，省 token）＝ `单文件版`（自包含，最省事）。

## 能干什么

- **前期规划与图纸设计**：户型优化、施工图审核、设计服务选型、装修模式决策
- **报价单 / 合同四道筛子审核**：数字勾稽（空白格与零值扫描、房态反推）、当地价格区间对标、条款与责任清单、法规安全红线；风险定级、7 段式输出、可直接照念的谈判话术
- **付款红线内置**：开工前累计付款 > 40% 一律不签（名目累加、以拆除进场前为界、分母为合同价 + 水电封顶价）
- **硬装施工全工种**：拆改、水电、瓦工防水、木工吊顶、油工墙面五大工种的标准工艺、材料选型与量化验收指标
- **主材全品类比价**：瓷砖、室内门、定制柜、地板、卫浴、门窗封阳台
- **全屋电器选型**：选型参数、水电气烟四路前置预留、国补三步计算、烟道止逆阀与燃气热水器安装坑
- **软装与全屋智能**：风格配色、单品选型；入门/中端/高端三档方案、生态对比、布线前置要求
- **预算与合同**：预算拆分模板、审核 10 步法、3331 付款法、增项防控、霸王条款识别与维权路径
- **竣工验收**：分项验收标准、环保检测、开荒保洁与软装进场时序
- **存量房旧改与政策金融**：旧房翻新全流程、公积金提取装修（须先问城市再核实当地）、家装贴息、旧改补贴、国补中央与地方自主品类
- **适老化改造与装配式装修**：四大空间适老化清单与补贴、装配式选型与适用场景
- **AI 效果图**：户型图/毛坯照 → 空间事实卡 → 70-20-10 配色 → 中英双版提示词 → 三条生成路线 → 12 项评审
- **装修工作台**：单文件 HTML 六页看板 + 五张云端数据表双向同步 + 离线降级 + 公开链接

## 使用示例

- 我刚拿到房子准备装修，帮我梳理全流程并给出可落地的方案建议
- 帮我审核这份装修报价单/合同，指出漏项、增项风险与谈判要点
- 我在某城市，房子某平米，预算某万，帮我做预算分配方案和避坑清单
- 这是我的户型图，帮我出一版奶油风效果图，并给可复用提示词

## 部署三步（通用）

1. **选形态**：能用 skill 目录 → 用目录；只能用对话框 → 用单文件版。
2. **配指令**：`SKILL.md`（或单文件版第一、二章）贴进角色设定 / 系统提示词。
3. **配知识**：把 `references/`（或单文件版后半部分）作为知识库上传；打开联网开关，价格与政策才准。

## 维护要点

1. 政策类内容（模块 7.5 国补、模块 10 旧改政策金融、模块 11 适老化与装配式）每年至少复核一次；答复前先问城市再联网核实。
2. 价格类输出必须带「参考区间，具体以当地门店实时报价为准」。
3. 修改 `references/` 后若同时维护单文件版，需重新生成，避免两版内容漂移。
4. 涉结构拆改、燃气、用电，一律先讲法规红线，再谈做法。
