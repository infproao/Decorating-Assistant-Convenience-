## 1. 结构核验与拆改合规流程（动墙前必走）

### 五步核验

| 步骤 | 动作 | 输出物 |
|------|------|--------|
| ① 查图 | 向物业索取**结构施工图/承重结构图**（物业有提供义务） | 图纸复印件或照片 |
| ② 初判 | 图纸上实心填充/黑色粗线墙为承重墙；外墙、配重墙（阳台与房间之间窗下墙）、剪力墙、构造柱、梁、管道井墙均不可拆 | 承重结构清单 |
| ③ 现场验证 | 敲击听声（空心 vs 实心）、查看墙体厚度（≥24cm 多为承重）、钢筋探测仪检测 | 现场判断记录 |
| ④ 专业确认 | 聘请结构师/有资质加固公司现场勘察，出具书面意见 | 书面勘察意见 |
| ⑤ 报备 | 向物业提交拆改方案与结构意见，办理装修备案/押金手续 | 备案回执 |

**勘察费参考区间**：200-500 元/次（地区差异大，以当地为准）。这笔钱不能省——**拆错承重墙的代价是整栋楼安全与刑事责任**。

### 绝对禁止清单

- 拆承重墙、剪力墙、构造柱、梁、楼板
- 拆阳台配重墙（窗下矮墙）、铲薄外墙保温层外的墙体
- 在承重墙上开横向长槽（横向开槽长度 >50cm 严重削弱结构）
- 扩大门窗洞口未做加固、切断墙体钢筋
- 拆改公共管道井、烟道、消防管线、燃气管道（燃气改动必须由燃气公司实施）

### 合法拆改后的配套动作（拆填充墙并入相邻空间时常见）

1. 断口处理：拆除面抹灰找平，新旧墙接缝挂网防裂。
2. 保温与防水：若拆的是与室外相邻的填充墙（如北阳台），须重做内墙保温（如 50mm 岩棉）+ 防水，并重做闭水试验 48h。
3. 门窗更新：涉及外窗更换时选断桥铝（常用 70 系列、双层中空、传热系数 K ≤2.0 为常见要求，以当地节能标准为准）。
4. 水电扩展：新增空间要补点位，需在水电阶段一次性做完，事后开槽代价高。
5. 结构柱保留：中部结构柱不可拆，做成书架背板/装饰柱是常规处理手法。

## 2. 隐蔽工程留证规范（事后扯皮的唯一凭据）

### 三条铁律

1. **先拍照后覆盖**：封槽、贴砖、封吊顶前必须拍照/录像，覆盖后再无机会。
2. **照片要有参照**：拍管线时放卷尺或参照物，纯管线照片无法证明位置与尺寸。
3. **归档成图**：拍完要整理成"水电走向图"，标注距墙/距地尺寸，交房时给用户一份。

### 留证节点清单

| 节点 | 必拍内容 | 用途 |
|------|----------|------|
| 开槽完成未布管 | 全屋槽道全景 + 关键处尺寸 | 证明未横向开长槽、未伤结构 |
| 布管完成未封槽 | 管线走向、接头、间距、固定卡 | 验收与维修定位 |
| 打压试验 | 压力表读数（≥0.8MPa，30 分钟压降 ≤0.05MPa 为常见标准，以验收规范为准）+ 读数特写 | 证明水路无渗漏 |
| 防水施工 | 涂刷遍数、高度（淋浴区 ≥1.8m、其余 ≥0.3m 为常见要求）、管根加强处理 | 防渗漏争议 |
| 闭水试验 | 蓄水前/中/后水位、时间、楼下顶面状况 | 见第 3 节 |
| 封窗/封阳台 | 型材壁厚、固定件间距、打胶、排水孔 | 渗漏与安全隐患 |
| 吊顶封板前 | 龙骨间距、吊杆固定、木作防火防腐、管线 | 变形与安全隐患 |
| 主材进场 | 包装型号、批次、数量、防伪码 | 防偷换材料 |

**交付物**：按"空间-工序-日期"命名的照片文件夹 + 一张水电走向图（标注关键尺寸）+ 一份影像资料清单。

## 3. 闭水试验与邻里配合争议处置（高频痛点）

### 标准做法

1. 防水涂刷完成并完全干燥后蓄水，水深 20-30mm（常见做法），**蓄水时间 ≥48 小时**。
2. 蓄水前通知楼下与物业，约定查验时间（建议选周末，便于对方到场）。
3. 蓄水期间定时记录水位（拍照带时间戳），结束后共同查看楼下顶面。
4. 无渗漏 → 双方签字确认；有渗漏 → 放水重做防水，重做后重新闭水。

### 楼下不配合时的升级路径（逐级留证）

```
① 当面/电话沟通（录音、保存聊天记录）
      ↓ 无果
② 物业或社区介入协调，要求物业记录协调过程
      ↓ 无果
③ 书面通知（EMS 快递至对方预留地址，内件品名写明"闭水试验查验通知函"，
   保留快递单与签收记录；内容含：试验时间、地点、时长、逾期不查验的处理方式）
      ↓ 无果
④ 物业/社区工作人员在场见证下自行试验，全程录像（起止时间、水位标记、蓄水过程、
   放水后楼下顶面状态），试验后再次通知查验并留存记录
      ↓ 仍无回应
⑤ 视为其放弃本次查验权利，保留全套证据后继续后续工序
```

### 特殊情形

| 情形 | 处理 |
|------|------|
| 楼下为空置房、失联 | 物业出具无法联系的证明；可采取**登报公告**方式（公告期常见 30 天），期满视为送达，避免"未穷尽通知方式"的程序瑕疵 |
| 楼下为出租房 | 要求业主提供租户联系方式，或出具授权委托书委托租户查验 |
| 试验期间楼下恰好出现漏水 | 立即停止试验，通知对方与物业共同确认原因并留证，避免被认定为己方责任 |
| 对方要求拆其吊顶检查 | 未经允许**无权强行进入并拆除**，须协商一致或走司法程序 |

### 责任逻辑（用于沟通，非法律意见）

- 邻里双方互负配合义务；无正当理由拒不配合查验，属不履行相邻关系配合义务。
- 若已按规范施工、充分通知、完整留证，后续发生漏水：**能鉴定为防水质量问题** → 由施工方/业主承担（但因对方拒检导致原因无法查清的，可主张减轻己方责任）；**因对方拒检导致原因无法查明** → 对方可能承担主要责任。
- 关键就在"证据链完整"：通知留痕 + 全程录像 + 第三方见证。

### 通知函模板（可复制）


## 4. 定制柜类落地规范模板（八段式，可直接交商家）

写定制柜需求时按这八段输出，商家无法偷换概念、报价也对齐：

| 段 | 内容 | 示例 |
|----|------|------|
| ① 结构分段 | 柜体横向/纵向如何分段 | 四段式：地柜+中部留空台面+吊柜+通顶收口 |
| ② 尺寸 | 外廓尺寸 + 各段内净尺寸 + 进深 + 离地高度 | 长 1940×高 2400×深 380；中部留空台面高 300-400 |
| ③ 功能配置 | 每段放什么、层板可调、特殊五金 | 底部悬空 200-220 带感应灯带；换鞋凳；挂衣区 |
| ④ 门板 | 门型、材质、饰面、颜色、拉手形式 | 平板无拉手 45° 斜切；PET 肤感哑光深灰 |
| ⑤ 灯光 | 灯带位置、色温、开关方式、变压器藏位 | 台面上方灯带 3500K，人体感应，变压器藏检修口 |
| ⑥ 水电配合 | 需预留的插座/开关/网络位及高度 | 台面上方 2 个五孔（距台面 150）；强弱电箱暗藏留 80mm 夹层 |
| ⑦ 验收表 | 逐项可勾选的验收标准 | 见下 |
| ⑧ 冲突提示 | 与建筑冲突/需现场确认的点 | 电箱位置、踢脚线、门套、插座冲突、顶面不平 |

**验收表通用条目**（每次都适用）：

- [ ] 外形尺寸与图纸一致，误差 ≤3mm；柜体垂直度、水平度达标
- [ ] 门缝均匀（2-3mm），开关无异响、无自开；抽屉推拉顺滑
- [ ] 封边完整无崩边、无开胶；板面无划痕、无色差
- [ ] 五金为合同约定品牌型号；铰链带阻尼
- [ ] 灯带发光均匀无暗区，变压器可检修
- [ ] 与墙面/顶面收口打胶均匀，无大于 3mm 的缝
- [ ] 内部插座/开孔位置与电器尺寸匹配，孔位封边
- [ ] 柜内无异味刺鼻（环保等级符合约定，保留检测报告）

**下单前必确认**：肤感膜品牌与抗指纹工艺、柜体板材环保等级（ENF/E0）、背板厚度（≥5mm 为宜）、是否通顶（通顶需处理顶面不平）、拉手形式（反弹器故障率高，优先斜切或明装）。

## 5. 设备安装交底单通用模板（以中央空调/风管机为例）

安装类翻车多因"安装前没交底"。通用字段：

```
【设备信息】品牌型号 / 匹数与制冷量 / 能效等级 / 购买渠道与安装方 / 保修与售后电话
【安装位置】室内机位置与朝向 / 出回风口净距（回风口与出风口间距 ≥ 一定距离，避免气流短路）
           / 检修口位置与尺寸（≥400×400，必须能触及电机与接线盒）
【吊顶配合】吊顶下吊高度 / 预留尺寸 / 冷凝水坡度与排放点 / 铜管与排水管走向
【电源要求】是否需独立回路 / 空开规格 / 线径 / 是否需漏电保护 / 线控盒位置与预埋管
【打孔要求】孔径、位置、外倾斜角度（内高外低防倒灌）、是否避开承重梁与钢筋
【施工时序】与水电/木工/油工的交接节点；打压与抽真空要求；调试与试运行
【验收标准】出回风温差（制冷工况常见 8-12℃，以产品说明为准）、无漏水、无异常噪音、
           排水通畅、风口无凝露、线控与远程控制正常
【责任划分】设备质量问题 vs 安装问题 vs 装修配合问题的责任边界与联系人
```

其他可套用本模板的设备：新风、地暖/壁挂炉、热水器、集成灶、洗碗机、嵌入式冰箱、电动晾衣机、浴霸。

## 6. 家电/主材口碑与质量核查方法（下单前自查）

### 四步核查

1. **看上市时间**：新品上市 <6 个月的慎买（首批量产问题未暴露）；上市 12-24 个月为较稳妥窗口。
2. **看差评聚类**：不看好评，专看差评；重点看是否**同一问题反复出现**（如"半年后漏水""主板烧了""异响"），单一差评是个案，同类聚集是批次缺陷。
3. **看关键故障词**：漏水、主板故障、异响、异味、虚标、结垢堵塞、电池/续航、售后推诿——这些词的出现频率比总评分更有信息量。
4. **看售后与配件**：保修年限、是否上门、配件价格与可得性、当地是否有授权维修点。

### 风险分级与处理

| 等级 | 判定 | 处理 |
|------|------|------|
| 高风险 | 同类故障集中、涉及安全（漏水泡柜、起火、门锁死） | 规避，换型号或品牌 |
| 中风险 | 个别问题、软件/固件类、安装依赖强 | 可买，但需确认固件版本、安装方资质、延保 |
| 低风险 | 偶发个案、口碑稳定 | 正常下单 |

**高价大件额外核查**：是否享受当期国补（补贴品类、比例、上限、参与门店/平台须核实）、安装费是否另计（打孔、加管、支架常见加钱项）、是否需提前预留尺寸与水电点位。

## 7. CAD 图纸读图与面积校准法

```python
# PDF 图纸转高清 PNG 后读图（4x 渲染保证线条清晰）
import pymupdf
doc = pymupdf.open("floorplan.pdf")
doc[0].get_pixmap(matrix=pymupdf.Matrix(4, 4)).save("floorplan_4x.png")
```

**面积校准**（图纸标注了总面积时，用面积反推比例尺，比量单条线更准）：

```
线长比 = √(实际面积 ÷ 像素面积)
实际长度 = 图上像素长度 × 线长比
```

**读图识别要点**

| 图元 | 含义 |
|------|------|
| 黑色/深灰实心填充墙、粗实线 | 承重墙或剪力墙（须再经结构核验） |
| 细线/空心双线 | 填充墙（一般可拆，仍需核验） |
| 斜线填充方块 | 构造柱 |
| 虚线 | 吊顶轮廓、梁或上方构件 |
| 四分之一圆带门线 | 门洞及开启方向 |
| 指北针 | 朝向（多数图上北下南，以指北针为准） |

**无标注尺寸时的反推常识**：开间 3.0-3.9m、进深 3.3-4.5m、室内门洞 0.8-0.9m、入户门 1.0m、普通窗台高 0.9m、层高 2.7-2.9m。反推值必须标注"估算，以现场复尺为准"。

## 8. 信息溯源分级（A/B/C）

整理外部信息（短视频、笔记、论坛、商家宣传）时按可信度分级，避免把营销内容当标准：

| 级别 | 来源 | 处理 |
|------|------|------|
| **A 可靠** | 国家标准/规范原文、政府部门公告、品牌官网参数、有资质的检测报告 | 可直接采用 |
| **B 参考** | 行业媒体、专业设计师公开分享、多个独立来源交叉验证过的经验 | 采用时注明来源，关键处二次核实 |
| **C 存疑** | 短视频口播（无字幕无文字描述）、带货笔记、单一来源的"行业揭秘"、无法复现的说法 | 不写入正式方案；如确需采用，必须标注存疑并二次核实 |

**抓取外部内容的方法（通用）**：短链用 `curl -I -L` 解析 302 跳转得到真实 ID，再拼原始链接获取；图文内容通常有完整文案可提取，**纯口播视频无法文本化，只能靠字幕或转写**，不要臆测其内容。所有引用保留原始链接与抓取日期。

## 9. 高频沟通话术模板

**向装修公司要报价明细**
> "请把报价按「项目-单位-数量-单价-品牌型号-工艺做法-备注」七列拆开，同一项目有多道工序的分开列。含糊项（如'按实际结算''详见现场'）请写明计价规则与上限。"

**拒绝恶意增项**
> "这项在合同与图纸里都没有，属于新增项目。请先出具书面变更单，写明项目、数量、单价、工期影响，我签字确认后再施工；未确认的部分不计入结算。"

**要求整改**
> "这一项不符合第 X 条约定/验收标准（具体描述 + 照片）。请在 X 日内整改完毕，整改后我方复验；逾期未整改的，按合同第 X 条处理。"

**催工期**
> "按进度表，本节点应于 X 月 X 日完成，现已逾期 X 天。请书面说明原因与补救计划，并明确新的完工日期及逾期责任。"

**主材进场核验**
> "请提供本批次的品牌、型号、规格、数量、防伪码与检测报告，我逐一核对后再拆封施工；与合同不符的请更换。"
