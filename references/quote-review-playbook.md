# 报价单 / 合同审核操作手册（四道筛子）

> 本手册是 `references/knowledge-base.md` 模块7.2（报价单审核方法）、模块7.4（增项防控）、模块8.1（合同审核）与 8.3（维权）的**可执行操作层**。
> 分工：问「审什么、什么标准」查 `references/knowledge-base.md`；要动手审一份具体报价单，走本手册；审**合同条款**走 `references/contract-review-playbook.md`；**报告版面**走 `references/report-template-html.md`（默认交付单文件 HTML 五色报告）。
> 价格均为 2026 参考区间，须联网核实当地实时价；无法联网则标注来源限制，禁止拒绝作答。

---

## 一、审核五步（不得跳步）

1. **读取与还原**：把报价单全部内容逐行读出——表头、每一行项目、单位、单价、数量、合计、备注、页脚小字、底部注释。扫描件 PDF 或图片逐页完整识别，不得跳页。读完后先向业主复述关键信息（小区/面积/总价/包含的分区），确认没读错再往下走。
2. **数字勾稽**：不依赖任何外部信息，必须先做完（见第二道筛子）。
3. **补外部基准**：联网核实当地人工与主材行情价；无法联网改用下方参考区间并明确标注。
4. **条款与法规扫描**：第三、第四道筛子。
5. **定级出报告**：按输出模板。

信息不全时，**先完成数字勾稽再问补充**，不得因信息缺失拒绝作答。

## 二、第一道筛子：数字勾稽（七条硬规则）

| 规则 | 判定 | 命中意味 |
|---|---|---|
| 单价 × 数量 = 合计 | 误差 > 1 元即异常 | 口径不明，总价不可信 |
| 分类小计 = 组内各行之和 | 必须分毫不差 | 对不上 = 有行漏计 |
| 各小计 + 管理费 + 设计费 + 税金 = 总价 | 差额须能解释 | 差额 = 隐性漏计 |
| **空白格与零值扫描** | 单价空、数量 0、合计空全列入 | **空白格 = 未定价 = 开工后按实数结算**，最常见增项入口 |
| 工程量 × 户型面积交叉验证 | 分项面积之和应 ≈ 房间面积 | 反推房屋真实状态、查少算工程量 |
| 工序完整性 | 有防水须有闭水；有贴砖须有找平/背胶；有乳胶漆须有基层；有吊顶须写龙骨封板 | 缺工序 = 后期必补价 |
| 备注与正文冲突 | 备注不得推翻已约定规格 | 正文已写规格、备注却「另收」= 明知故犯预留增项 |

### 房态反推技巧

报价单若出现地砖拆除、墙地砖拆除、木地板拆除、橱柜/洁具/吊顶拆除、回填拆除、拆后修补、垃圾外运 → 这份单子是照「已装修过的房子」量的。

若业主说是毛坯新房 → 这批项目应整批删除，并提示「设计师连房屋现状都可能搞错，其余工程量需现场复尺」。

## 三、第二道筛子：价格行情（参考区间，须联网核实当地价）

> 2026 参考值，单位元/㎡（含水电的半包综合价，包水管按根计）。**须联网核实当地实时价**；无法联网按下表并标注来源限制。

| 项目 | 一线/新一线 | 二三线 | 三四线 | 偏离判定 |
|---|---|---|---|---|
| 半包综合单价（含水电） | 700~1000 | 550~800 | 450~700 | 低于下限警惕漏项，高于上限要砍 |
| 水电改造（按建面包干） | 110~160 | 85~130 | 70~110 | 不封顶的按实结算一律视为风险 |
| 防水（2 遍） | 40~60 | 30~50 | 25~40 | 超上限且遍数 < 2，双重不合理 |
| 地砖铺贴 | 50~80 | 40~70 | 35~55 | 大板（≥600×1200）可上浮 10~20 |
| 墙砖铺贴 | 55~85 | 50~80 | 40~65 | 大砖上浮须写明条件 |
| 包水管 | 200~300 元/根 | 180~250 元/根 | 150~200 元/根 | 明显超上限即偏高 |
| 乳胶漆（含基层） | 30~45 | 25~38 | 20~32 | 只报人工不报材料须追问口径 |
| 美缝 | 18~30 | 15~25 | 12~20 | — |
| 管理费 | 工程造价 5%~8% | 同左 | 同左 | > 10% 或「轻辅+主材」双头收要谈 |
| 设计费 | 工程造价 3%~8%，或 30~200 元/㎡ | 同左 | 同左 | 无明细的服务费等同此项 |

**判定原则**：单价偏离区间本身不等于有问题（工艺档位不同会合法浮动），但**「偏离区间 + 备注含另收/按实结算」同时成立**，即坐实为增项陷阱。

## 四、第三道筛子：条款与责任（缺一条即计入高危）

| 必备条款 | 基准要求 | 缺失后果 |
|---|---|---|
| 付款节点 | 开工前 ≤ 30%；做一项验一项付一项；尾款 ≥ 5% | 开工前付 60%、瓦工完付到 95% = 交付前失去全部制约 |
| 质保金 | 5%~10%，验收合格满约定天数后支付 | 无质保金 = 售后无抓手 |
| 工期 + 逾期违约金 | 明确起止日期与每日违约金 | 无约定则拖延无法索赔 |
| 质保期 | 最低 2 年；厨房卫生间防渗漏 5 年 | 约定短于法定期限无效 |
| 增项上限与书面签证 | 增项须书面确认，累计超合同价 5% 须签字 | 「未涉及项目以实际施工数量为准」= 无限增项授权，必须改 |
| 材料验收与型号锁定 | 进场验收 + 写明品牌**和型号** | 只写品牌不写型号 = 可调包 |
| 双方签署 | 甲乙双方签字 + 公司盖章 + 日期 | 只有甲方签字栏 = 业主被单方锁定，对公司几无约束力 |
| 验收标准 | 关键工序要有量化指标（平整度 ≤ 2mm、闭水 48 小时等） | 无标准则「合格」由乙方说了算 |

### 付款红线（全流程硬规则，优先于价格、口碑、方案、工期）

**开工前累计付款超过 40%，一律不签。没有例外。**

- **算准口径**：时间以**拆除进场之前**为界；名目包含定金、意向金、锁价金、签约款、开工款、备料款、材料采购款、主材代购款、水电预收、工人进场费等**全部**；公司把 50% 拆成「签约 25% + 开工 25%」的，**必须累加**；分母用预计落地总价（合同价 + 水电封顶价），不用不含水电的「优惠总价」。
- **判级**：≤ 30% 🟢 合理 / 30%~40% 🟠 要往下压 / **> 40% 🔴 一律不签**。
- **报价单或合同里找不到付款条款的**，按未定稿处理，不要签。
- 不接受「这是制式合同」「别人家都这样」「找好人就相信」「他家总价最低」作为例外理由。
- 理由不是钱，是**筹码**：工程还没开始就把四成以上付出去，出问题时手上没有任何可撤回的东西。

> 与 `references/knowledge-base.md` 模块8.1 的 3331 付款法关系：3331（30/30/30/10）是**争取目标**，40% 是**不可越过的硬红线**。

### 订金 / 定金红线（独立一条，与 40% 并列）

**先分清名目，再谈额度——两者法律后果完全不同。**

| 名目 | 性质 | 红线 |
|---|---|---|
| **订金 / 意向金 / 诚意金** | 预付性质，**不是定金**：不适用违约双倍返还罚则，对方违约只能要回本金 | **≤ 5,000 元，越低越好**（争取 0～2,000；>1 万直接不交） |
| **定金** | 法定概念，有罚则；《民法典》第 586 条上限为主合同标的额 **20%**，超过部分不产生定金效力 | 能不给就不给；要给 **≤ 合同价 5%** |
| 量房费 / 设计定金 / 锁价费 | 换名头的收费，常与订金叠加 | 合并计入上面额度，**不得重复收取** |

- 必须书面写明三件事：**未开工全额可退** + **退款时限（如 7 个工作日，原路退回）** + **全额抵首期工程款**。只写"可退"不写时限 = 事实上不退。
- 判级：订金 ≤5,000 🟢 / 5,000～1 万 🟠 压 / **>1 万、「三笔并行都不退」、「一经支付不予退还」🔴 不交钱、不签**。
- 已经在没合同的情况下交了订金 → 先书面（留痕）主张未开工应退，再走 12315 / 住建部门 / 消协；不要只口头协商。

**付款方式只推荐一种：验一付一。** 做一项、验一项、付一项；开工前合计 ≤30%（硬红线 40%）；竣工留 5%、质保金 10% 入住三个月后付。对方提"签约付 50%""开工付 70%"一律按红线处理。

> 话术：「付款我只接受验一付一，开工前不超过 30%，每项验收合格再付下一项，质保金 10% 入住三个月后结。订金我最多给 5,000，写清未开工全额可退。这两条不写，价格谈得再好也签不了。」

## 五、第四道筛子：法规与安全（红线，一票否决，不谈钱）

- **承重墙、剪力墙、梁、柱一律不得拆改**。报价单含拆墙项 → 必须提示：动工前拿物业结构图核验，必要时请结构师确认；非承重墙新建位置与过梁做法也需确认。
- 燃气管道不得私自改动，须由燃气公司或有资质单位施工。
- 卫生间防水必须做闭水试验（≥ 48 小时），并延伸到门洞外侧。
- 电路须分色、接地、装漏保；水路须打压试验。
- 竣工后室内环境污染物浓度须符合国标。
- 凡涉及结构拆改，一律提示「须经物业与原设计单位或同资质设计单位出具方案，不得擅自施工」。

## 六、常见漏项清单（逐项核对报价单是否含）

厨卫集成吊顶（铝扣板）、窗台石与过门石、踢脚线、暖气改造（拆改/移位/加片）、打孔费、烟道止逆阀、五金与灯具安装费、开荒保洁、美缝、包立管、门洞抹灰/修补、垃圾外运、材料上楼费、成品保护。

**特别注意**：「业主自购清单」与「施工报价」都不包含的项目 = 责任空白，必须追问「谁做、含不含、何时做」。

### 漏项归属三分法（先分类，再算钱）

一头热把"单子上没有的"全算成施工方漏项，会得出虚高的增项总额，谈判时被对方一句"这个本来就是我们自己买的"顶回来。**必须逐项判归属**：

| 类别 | 判据 | 处理 |
|---|---|---|
| **A 类 真漏项** | 该工序属施工方职责范围（防水、找平、回填、止逆阀、保洁、垃圾外运、窗帘盒、石膏线、收口件） | 计入增项金额，要求写进总价或注明"另计约 X 元" |
| **B 类 第三方 / 业主自理** | 法定只能由专营单位施工（燃气、暖气、承重结构鉴定）、或业主自行安排的（空调打孔、部分灯具洁具甲供） | **不计入本单金额**，只要求写清"配合开孔/收口/修补，不另收费" |
| **C 类 已解决 / 已置换** | 已提供、已赠送、已折算成其他项目（如面板置换成柜体） | 不计金额，只补一句书面确认：什么已含、置换为什么、不再另计 |

输出报告时，A/B/C 分三张表列出，**总额只累加 A 类**，并在合计处注明"已扣除 B、C 类 X 元"。这样总额才站得住，话术也才不会被打回。

> 置换特别提醒：赠品、面板、五金换成别的东西（如柜体、延保、增项抵扣），必须书面写清"原项取消、置换项是什么、是否产生差价"，否则两头都算一次。

## 七、定级模型

**风险值 = 金额敞口 × 发生概率 × 不可逆程度**

- 金额敞口：> 1 万 = 高；3000~1 万 = 中；< 3000 = 低
- 发生概率：条件已成立必然触发 = 高（如正文已写规格、备注却另收）；视现场情况 = 中；概率性 = 低
- 不可逆程度：签了改不了 / 做了拆不掉 / 钱付了要不回 = 高；开工前还能谈 = 低

三项皆高 → 🔴 极高；两项为高 → 🟠 高；一项为高 → 🟡 中；均可逆且金额小 → ⚪ 低。

## 八、输出模板（严格照此结构）

**默认交付单文件 HTML 五色报告**（版式与组件见 `references/report-template-html.md`）：🔴 高危不改不签 / 🟠 要谈 / 🟢 合理或应争取的目标 / 🟡 提醒 / 🟣 唯一推荐。用户在聊天里看，则改用下方 Markdown 结构并保留 🔴🟠🟢🟡🟣 前置标记。

1. **结论先行**：三句话说清——总价多少、实际落地大概多少、现在能不能签。
2. **高危点表格**：`| 等级 | 高危点 | 金额敞口 | 为什么危险 | 处置动作 |`，按风险值从高到低，至少列全 🔴 项。
3. **漏项清单**：报价单没有但施工大概率遇到的项目 + 估算金额。
4. **悬空项清单**：所有「只有单价没数量」「数量 0」「合计空」的项目 + 敞口估算。
5. **谈判要点**：3-5 条，每条写成可直接照念的一句完整话（见话术库）。
6. **签字前打勾清单**：10 项左右。
7. **免责与提示**：价格时效；效果图/报价单 ≠ 合同；拆改须核验结构。

## 九、话术库（每条都是可直接照念的完整句）

- **付款**：「付款我最多开工前 30%，每项验收合格再付下一项，留 10% 质保金，改不了这份合同我就签不了。」
- **封顶**：「水电必须给封顶价，按建筑面积包干，我要一个签完就不变的数字，不接受按实结算。」
- **悬空项**：「这几项只有单价没有数量，等于空白支票。要么把数量填实，要么改成包干，不然我没法比价也没法做预算。」
- **增项条款**：「备注里‘以实际施工数量为准’这句要删掉，改成‘增项累计超合同价 5% 须我书面确认，未确认我有权拒付’。」
- **冲突加价**：「墙砖正文已写明是 800 长的全瓷，备注再加 35 元每平属于重复计价，请并进单价里。」
- **材料**：「材料请写清品牌和型号，进场的每一批我要验收，型号不对我不签字。」
- **赠品**：「开关面板、美缝、烟机灶具这几样赠品排在付完全款之后才装，能不能折现？或写进合同附件，注明品牌型号和交付时间。」
- **漏项**：「这份单子里没有暖气改造、厨卫吊顶、窗台石和踢脚线，请明确由谁做、含不含在总价里。」

## 十、硬性约束

1. 所有价格标注「参考区间，具体以当地门店实时报价为准」。
2. 不凭空臆测工程量；工程量问题只能提示「需现场复尺确认」。
3. 不推荐单一品牌，只做梯队划分与参数对比。
4. 涉及结构拆改、燃气、用电安全，必须明确提示法规限制与核验义务。
5. 不声称审核具有法律效力；重大争议建议咨询当地住建部门或律师。
6. 联网失败只重试 1 次，之后降级为参考区间并明确标注，不得中断作答。
7. 业主情绪化抱怨时，先接住情绪，再回到事实与条款。
8. 涉及政策金融（公积金/贴息/补贴），必须先确认城市与房龄/产权，再联网核实，禁止套用其他城市政策。
