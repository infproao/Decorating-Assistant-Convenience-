# 装修工作台搭建（Workbench Builder）

本技能为用户提供「装修工作台」的一键搭建服务：单文件 HTML + 资料库数据表云端存储 + 公开在线链接。**执行前必须先读取 `references/workbench-prompt.md` 获取完整需求规格（含 6 页模块、5 张数据表、SDK 调用形态、全部迭代补充），禁止凭记忆简化。**

## 何时加载本技能

用户出现以下任一意图：要求搭建「装修工作台」；要求装修进度/预算/待办管理页面或应用；要求把装修数据做成在线看板；提到 workbench-prompt / 装修工作台复刻。

## 执行流程（六步，严格串行）

### 第 1 步：需求确认（简短）
- 确认数据归属：默认**单用户自用**。必须向用户说明：公开链接所有知道 URL 的人均可访问数据表，若含敏感信息（地址/金额敏感项）建议不外传链接
- 确认是否需要预置示例数据（默认预置，严禁空白首屏）

### 第 2 步：读取规格
- 读取 `references/workbench-prompt.md`，该文件为**最终整合版提示词**（v4，含原 v1-v3 全部迭代 + 12 处审查补充），作为实现规格逐条执行
- 特别注意补充章节：同步冲突策略、降级判定与回迁、图片云端 URL 方案、CSV 导入容错、时区与金额精度、验收 DoD

### 第 3 步：资料库环境准备
- 按规格建 5 张数据表（施工任务/预算明细/装修档案/灵感库/施工照片），字段与选项以规格第三节为准
- 逐一调用 `lint_schema`（canonical schema 5 份）与 `lint_database_sdk_usage`（5 个库），**两道 lint 全 OK 才可进入下一步**；任一失败先修复再重跑

### 第 4 步：实现单文件 HTML
- 全部 CSS/JS/SVG 内联，零外部依赖；黑白灰冷色调、圆角卡片、系统字体栈
- PC 左侧边栏、手机底部 Tab（≥44px 点击区、输入框 ≥16px、安全区适配）
- SDK 形态：`window.SMART_PAGE.database` → `db`，每处调用内联字面量 `databaseId`；`onUpdated` 整页只注册一次（300ms 防抖）；query 用 `startCursor` 循环拉全
- 渲染函数严禁互调，统一 `refreshAll()` 调度；实现规格中的同步/降级/容错补充条款

### 第 5 步：导入与发布
- `import_html` 绑定 5 个 `databaseId` 上传
- `publish` 获取公开链接；**注意**：重新 publish 为覆盖更新原链接（若平台生成新链接，须告知用户旧链接作废）

### 第 6 步：交付与验收
- 交付公开在线链接 + 使用说明（添加到手机主屏方法）
- 按规格第十节 DoD 验收清单逐项自检并在回复中报告结果
- 提醒用户：首次打开含示例数据（1 条逾期任务 + 1 条超支预算），可用「清空示例」移除

## 铁律

1. **严禁空白首屏**：首次打开必须预置示例数据并附「清空示例」
2. **两道 lint 未全过禁止 import_html**
3. **图片一律引用云端 URL**（`uploadImage` 返回地址），禁止 base64 内联进 HTML 或数据表文本
4. **隐私数据不预填**：示例数据用虚构数据，不写入用户任何真实信息
5. 资料库能力不可用时：告知用户当前无法云端部署，可先交付 localStorage 离线版单文件 HTML（键前缀 `wb_reno_`），待资料库可用后再迁移
6. 所有价格计算以「分」为最小单位，货币统一 ¥，支出红/收入绿
