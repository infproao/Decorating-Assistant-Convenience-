# 装修工作台 · 最终版规格提示词（v4 全量整合版）

> 用途：交给具备「云端数据表 / 资料库」能力的 AI 平台，一键复刻同款工作台；若无此能力，可降级为 localStorage 离线版单文件 HTML。本版在 v1-v3 基础上补全 12 处缺口（同步冲突、降级回迁、图片方案、CSV 容错、时区精度、验收 DoD 等），为实现与验收的唯一依据。

## 一、整体要求

- 单文件 HTML，全部 CSS/JS/SVG 图标内联，零外部框架/CDN/字体/图表库；黑白灰冷色调、圆角卡片、系统字体栈
- PC 左侧边栏导航，手机底部 Tab（≥44px 点击区，输入框字号 ≥16px，适配底部安全区）；窄屏单列堆叠，表格横向滚动
- 页面右上角同步状态指示器（已同步/同步中/离线模式）
- 首屏有「导出 JSON 备份」「导出 CSV」「导入恢复」「清空数据（二次确认弹窗）」；表单内容自动暂存防丢失（localStorage），上传图片 IndexedDB 暂存防登录重定向丢失
- 首次打开预置示例数据（含 1 条逾期任务、1 条超支预算，均为虚构数据），附「清空示例」能力，严禁空白首屏
- 渲染函数严禁互调，统一 `refreshAll()` 入口调度；生成后过冒烟自检（调用链无环、DOM id 存在、空数据不崩、日期跨月跨年正确、空态文案正常渲染、降级模式下导出/导入一致）
- **时区口径【补充】**：全部日期一律 `YYYY-MM-DD` 字符串存储与比较；「今天」竖线、逾期判定、开工倒计时统一使用浏览器本地时区的当天日期
- **金额精度【补充】**：所有 ¥ 计算以「分」为最小单位（金额×100 取整后运算，展示时再除回），避免浮点误差污染执行率；货币统一 ¥，支出红色、收入绿色；金额展示带千分位

## 二、页面与模块（6 页）

### 1. 首页概览
- 顶部「今天要处理」：自动汇总逾期/今日/临期任务，逾期标红 + 一键完成按钮，昨日未完成顺延今日
- 4 张统计卡：工程进度、实际花销、剩余预算、待处理事项（数字与超支横幅标 `data-sp-bindable`/database 绑定）
- 装修档案卡：风格/面积/户型/总预算/装修方式/开工日期/开工倒计时，点击可编辑
- 超支横幅：首页与预算页同步高亮，点击弹出超支明细弹窗（仅列超支行）

### 2. 施工进度
- 固定 8 阶段：设计→拆改→水电→泥木→油漆→安装→软装→完工
- 每阶段可展开小项列表；甘特图（内联 SVG）按小项真实开始日/真实完成日绘制，含红色「今天」竖线；阶段起止与进度百分比由小项日期自动汇总

### 3. 待办清单
- 与施工小项同一份数据：挂了所属阶段=工程任务，不挂=日常待办
- 字段：任务名称、所属阶段、优先级（高/中/低）、分类（施工/采购/沟通/验收/其他）、截止日期、真实开始日、真实完成日、已完成、备注
- 筛选：类型/优先级/分类/状态；完成时自动写入真实完成日

### 4. 预算管理
- 字段：项目名称、预算分类（硬装/主材/家具/家电/软装/其他）、所属阶段（8 阶段）、预算金额¥、实际花销¥、品牌型号、备注
- 自动汇总：总预算/已花销/结余/执行率；按分类、按阶段两种维度切换
- 超支行标红，首页与预算页高亮超支横幅，点击查看超支明细弹窗

### 5. 灵感库
- 字段：描述、风格标签（多选：现代简约/奶油风/原木风/轻奢/新中式/北欧/法式/复古）、图片、收藏
- 上传图片自动压缩（最长边 ≤1000px，JPEG 质量 0.8，HEIC 转 JPG），全库上限 30 张；**【补充】第 31 张上传时拒绝并 toast 提示已达上限**；根据描述关键词自动猜标签并预勾选；标签筛选、只看收藏；卡片网格展示

### 6. 装修相册（时间线）
- 字段：描述、拍摄日期、图片；上传卡：描述 + 日期选择器（留空取当天）+ 多选照片（自动压缩，一次最多 9 张，逐张上传云端托管）；**【补充】相册与灵感库图片额度相互独立（相册不占 30 张上限）；单张 `uploadImage` 失败自动重试 2 次，仍失败则标记「未同步」并保留本地，下次在线时续传**
- 垂直时间线按拍摄日期倒序：圆点节点 + 日期 + 描述 + 缩略图网格；点击缩略图看大图，支持编辑（描述/日期）与删除

## 三、数据表（资料库建 5 张，字段与选项如下）

1. **施工任务**：任务名称(text)、所属阶段(select 8 阶段)、优先级(select)、分类(select)、截止日期(date)、真实开始日(date)、真实完成日(date)、已完成(checkbox)、备注(text)
2. **预算明细**：项目名称(text)、预算分类(select 6 项)、所属阶段(select 8 阶段)、预算金额(currency ¥)、实际花销(currency ¥)、品牌型号(text)、备注(text)
3. **装修档案**：项目名称(text)、装修风格(text)、面积(number)、户型(text)、总预算(currency ¥)、装修方式(select 全包/半包/清包)、开工日期(date)
4. **灵感库**：描述(text)、风格标签(multi_select 8 项)、图片(image)、收藏(checkbox)
5. **施工照片**：描述(text)、拍摄日期(date)、图片(image)

## 四、同步与降级【补充章节】

### 4.1 云端同步
- SDK 调用形态：`window.SMART_PAGE.database` 赋给 `db` 后用 `db.query/addRecord/updateRecord/deleteRecord/uploadImage/onUpdated`；每处调用内联字面量 `databaseId`；`onUpdated` 整页只注册一次（300ms 防抖）；query 分页用 `startCursor` 循环拉全
- **冲突策略**：同记录并发修改按「最后写入胜出」（整记录覆盖）；页面本地编辑未保存期间收到 `onUpdated`，保存时以本地最新值为准
- **删除同步**：`onUpdated` 后全量 diff 本地与远端 id 集合，远端已删除的记录本地同步移除（含关联图片引用清理）
- **重入保护**：`refreshAll()` 执行期间收到新的 `onUpdated` 触发，仅置「待刷新」标记，当前渲染完成后补跑一次，禁止并发渲染

### 4.2 离线降级
- **判定时机**：页面加载后首次 `db.query` 失败或 5 秒超时 → 进入离线模式；之后每次 `refreshAll` 重试一次云端，成功即切回在线
- **离线存储**：localStorage，键前缀 `wb_reno_`；图片在离线模式存 IndexedDB（压缩后 Blob）
- **数据回迁**：离线期间产生的本地新增/修改，切回在线时自动按记录推送云端（按更新时间戳，远端更新的记录保留远端值并 toast 提示冲突项）
- **状态指示**：离线模式下指示器显示「离线模式」，所有写操作本地生效并在状态栏标注待同步条数

### 4.3 图片方案
- **页面一律引用云端 URL**（`uploadImage` 返回地址），禁止 base64 内联进 HTML 或数据表文本；缩略图使用压缩版 URL，点开大图用原图
- IndexedDB 暂存仅作为上传失败/离线时的中转，不作为长期展示源

## 五、备份与导入

- 导出 JSON 全量备份；导出每表 CSV（带 BOM，Excel 可编辑后再导入，表头自动识别归属表）
- **【补充】CSV 导入容错**：日期接受 `2026/9/9`、`2026-9-9`、`2026年9月9日` 等格式并归一为 `YYYY-MM-DD`；金额接受千分位逗号、¥ 前缀、空值（记 0）；导入策略为**按记录 id 合并（存在则更新、不存在则新增）**，无 id 则追加；导入完成后显示「成功 N 条 / 跳过 M 条（含原因）」报告
- 导入恢复前自动做一次本地快照备份，支持一键撤销本次导入

## 六、数据安全

- 本工作台为**单用户自用**假设：公开链接所有知道 URL 的人均可访问数据表，含敏感信息（详细住址、大额预算等）时勿外传链接
- 隐私数据不预填，示例数据全部虚构；密码/确认机制仅防误触，不作为安全边界

## 七、工程与部署门槛

- 备选导入：支持 JSON 全量恢复 + 每表 CSV
- 上传前必须通过两道 lint：`lint_schema`（canonical schema 5 份）与 `lint_database_sdk_usage`（5 个库），全 OK 再 `import_html` 绑定 5 个 databaseId 上传，最后 `publish` 拿公开链接
- **【补充】publish 更新机制**：改版后重新 publish 为覆盖更新原链接；若平台返回新链接，须告知用户旧链接作废并以新链接为准
