# 合同审核操作手册（条款层）

> 报价单审的是**钱和量**；合同审的是**权和责**。
> 本手册处理「用户发来一份装修合同 / 施工协议 / 半包合同 / 全包合同 / 设计合同 / 定制家具合同，要我看有没有坑」的场景。
> 输出格式固定为 `references/report-template-html.md` 定义的五色报告（🔴 高危不签 / 🟠 要谈 / 🟢 合理或应争取的目标 / 🟡 提醒 / 🟣 唯一推荐）。
> 本手册不构成法律意见，重大争议建议咨询当地住建部门或律师。

---

## 一、审核顺序（先结构，后文字，最后算钱）

1. **清点附件**：合同正本 + 报价单 + 图纸 + 材料清单 + 付款计划。**附件不齐的合同，本身就是高危项**（"合同价以附件报价单为准"而附件没签字 = 价格悬空）。
2. **查主体资格**：签约方是公司还是个人；营业执照名称与公章是否一致；是否分公司/项目部签约（分公司无独立担责能力时要求总公司盖章或授权书）。
3. **查四要素闭环**：价款 ↔ 报价单 ↔ 材料清单 ↔ 图纸是否互相对得上、是否都有双方签字。
4. **逐条扫毒条款**（第三节清单）。
5. **算钱**：付款比例、定金比例、增项上限、违约金对等性。
6. **出报告**（按 `references/report-template-html.md`）。

---

## 二、必备条款清单（缺一条即计高危）

| # | 条款 | 基准要求 | 缺失后果 |
|---|---|---|---|
| 1 | 主体与授权 | 公司全称、统一社会信用代码、公章；代理人授权书 | 出问题找不到责任主体 |
| 2 | 工程概况 | 地址、面积、户型、承包方式（清包/半包/全包）、施工范围 | 范围不清 = 后期"这不在合同里" |
| 3 | 价款构成 | 总价 + 报价单为附件 + 是否含税 + 是否含管理费/设计费 | 总价口径可被随意解释 |
| 4 | **价款调整机制** | 变更须书面签证；增项累计超合同价 5% 须业主书面确认 | 无上限 = 无限增项 |
| 5 | **付款节点** | 开工前 ≤30%；按验收节点付；尾款 ≥5%；质保金 5%~10% | 失去全部制约 |
| 6 | **定金/意向金** | 合计 ≤10%（争取 ≤5%）；书面"未开工全额可退 + 退款时限 + 抵扣首期款" | 见第三节专章 |
| 7 | 工期 | 起止日期 + 顺延条件（须书面）+ 逾期违约金（日万分之几或固定额） | 拖延无法索赔 |
| 8 | 材料 | 品牌 + **型号** + 规格 + 环保等级；进场验收；替换须书面同意 | 只写品牌 = 可合法调包 |
| 9 | 变更与签证 | 变更单格式、谁签字有效、变更价款如何计 | 口头变更 = 事后漫天要价 |
| 10 | 质量与验收 | 分阶段验收节点、量化标准（空鼓率、打压、闭水 48h、平整度）、隐蔽工程拍照留档 | "合格"由乙方说了算 |
| 11 | 保修 | 基础 2 年、防水/防渗漏 5 年、水电 5 年；响应时限（如 48 小时到场） | 售后无抓手 |
| 12 | 违约与解除 | 双向违约金对等；业主解除权（逾期超 X 日可解除并索赔） | 只有乙方有权解约 = 单边条款 |
| 13 | 安全与责任 | 施工安全责任、第三者损害、物业罚款、成品保护责任归属 | 出事全算业主 |
| 14 | 争议解决 | 协商→诉讼/仲裁；管辖地（争取业主所在地法院） | 约定异地仲裁 = 维权成本高于损失 |
| 15 | 附件与签署 | 附件清单、双方签字 + 公章 + 日期、页数骑缝 | 无章无日期 = 不是合同 |

## 三、定金 / 意向金专章（独立红线，优先于议价）

装修行业最常见的"套"，不是报价单做假，是**先收钱再谈价**。

### 三条硬规则

1. **先分名目**：订金/意向金/诚意金是**预付**，不退罚则不适用；定金才是法定概念。
   - **订金类**：合计 **≤ 5,000 元，越低越好**（争取 0～2,000），>1 万不交。
   - **定金**：能不给就不给；要给 ≤ 合同价 **5%**。法律上限 20%（《民法典》第 586 条），超过部分无定金效力。
   - 量房费/设计定金/锁价费合并计入上述额度，**不得重复收取**。
2. **退款条款**：必须写明「未开工全额可退」＋**退款时限**（如 7 个工作日）＋**退款方式**（原路退回）。只写"可退"不写时限 = 事实上不退。
3. **抵扣条款**：定金**全额抵扣首期工程款**，不得另立名目（"抵设计费"而设计费又不含在合同价 = 双重计算）。

### 五种高危写法（见到即判 🔴）

| 写法 | 为什么危险 |
|---|---|
| "意向金一经支付不予退还" | 无论何种原因都不退，包括对方违约 |
| "定金"与"订金""意向金""诚意金"混用 | 法律上"定金"有罚则（不履约双倍返还），"订金"无此效力；混用＝事后按对他有利的解释 |
| 三笔并行：量房费 500 + 设计定金 2,000 + 意向金 5,000，各自写"不退" | 表面单笔便宜，合计已超 10% |
| 定金 > 合同价 20% | 超出部分本无定金效力，却仍写"不退" |
| 收定金时无合同、无报价单、无收据 | 只有转账记录，事后连"这笔钱是什么"都说不清 |

### 处置口径

- 定金比例 > 10% → 🟠 压到 5%~10%，并加退款条款。
- 定金比例 > 20%、或"三笔并行都不退"、或"一经支付不予退还"且无例外情形 → 🔴 **不交钱、不签**，不用往下谈。
- 已交了定金才发现条款有问题 → 先书面（微信/邮件，留存）主张"未开工应退"，同步准备投诉（12315 / 当地住建部门 / 消协），**不要口头协商**。

> 话术：「意向金我可以付，但只付合同价 5%，并且写明三件事：未开工全额可退、7 个工作日内原路退回、全额抵扣首期工程款。这三条不写，这笔钱我不转。」

## 四、常见"毒条款"逐句清单

| 原句（常见写法） | 问题 | 改法 |
|---|---|---|
| "本报价单解释权归本公司所有" | 排除对方主要权利，法律上无效，但显示立场 | 整句删除，改为"本合同未尽事宜双方书面协商" |
| "工程量以实际发生为准，多退少补" | 无限增项授权 | "以双方签字确认的实测数据为准；单项增减超 5% 须业主书面确认，未确认部分不予支付" |
| "甲方未按期付款，乙方有权停工且工期顺延，甲方承担全部损失" | 单边违约条款 | 双向违约金对等；顺延须书面通知 |
| "工程质量以乙方验收为准" | 自己当裁判 | 按国标/地方标准 + 第三方检测 |
| "材料可用同等品质替代" | 调包的合法外衣 | "未经业主书面同意不得替换；替换须品牌型号同级且经确认" |
| "因甲方原因导致的延期，乙方不承担责任"（定义过宽） | 甲方"原因"可无限解释 | 明确列举 + 通知时限 |
| "施工期间水电费、物业押金、垃圾清运费由甲方承担" | 容易叠加重复收费 | 逐项核对是否已含在报价内 |
| "增项款项须在施工前一次性付清" | 增项先付钱，等于放弃验收权 | 增项纳入下一期节点款 |
| "保修期内人为损坏及不可抗力不在保修范围"（合理）＋"其他情况乙方不承担责任" | 后半句过宽 | 保留前半句，删除兜底免责 |
| "争议提交乙方所在地仲裁委员会仲裁" | 异地仲裁成本高于损失 | 改为工程所在地法院 |
| "本合同自甲方付款之日起生效" | 未付款则合同不成立，但已开工 | 改为双方签字盖章之日生效，付款为履行义务 |
| "甲方擅自终止合同，已付款项不予退还" | 无解除权 | 增加业主解除权与结算规则（已完工程量按实结算） |

## 五、判级与输出

**判级沿用 `references/quote-review-playbook.md` 第七节的风险值模型**，另加两条合同专属：
- 条款缺失但金额不可估 → 按"不可逆程度=高"处理，计入 🔴。
- 单边权利义务条款（只约束业主）→ 直接 🔴，不看金额。

**输出**：严格按 `references/report-template-html.md` 出 HTML 五色报告，章节用合同版结构：

1. 结论（能不能签 + 三个最关键问题）
2. 主体与四要素闭环
3. 付款与定金（含比例计算表）
4. 价款与增项机制
5. 工期、验收、保修
6. 单边条款与免责条款（逐句原文 + 改法）
7. 争议解决与签署
8. 缺失条款清单（附"补一条模板句"）
9. 谈判清单 A/B/C
10. 五条 pass 红线

金额可算的必须算给用户看（例：定金 30%＝2.2 万，压到 5% 可减少 1.8 万前置敞口）。

## 六、硬性约束

1. 不声称审核具有法律效力；不说"这合同无效"，只说"这条可能被认定无效，建议改"。
2. 不替用户拟完整合同文本，只给「这一条改成这句话」级别的替换句。
3. 涉及结构、燃气、消防、资质（如涉及拆改、明火作业），只提示法定要求与核验义务。
4. 涉及金额一律给区间并标注估算口径。
5. 用户已签/已付款时，输出重心转为「补救路径 + 留证清单」，不再纠缠"当初不该签"。
6. 情绪化抱怨先接住，再回到条款原文。
