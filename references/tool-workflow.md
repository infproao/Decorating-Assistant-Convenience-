# 生图工具工作流（通用）

> 覆盖：路线选择 → 读图方法 → 各平台参数 → 图生图 / ControlNet 约束生成 → 抽卡迭代 → 故障排查。
> 工具版本与定价变化快，涉及具体价格与版本时须搜索核实；本文件只提供稳定方法与参数区间。

---

## 一、路线选择决策树

```
手上有什么素材？
├─ 只有文字描述（无图）
│   └─ 路线 A：文生图。出"氛围概念图"，明确告知用户：空间比例与真实户型无关，仅供风格确认。
├─ 有毛坯房照片
│   └─ 路线 B：图生图（参考图 = 毛坯照）。空间结构贴合度最高，推荐首选。
├─ 有户型图 / CAD
│   ├─ 内置工具 → 路线 B：户型图作参考图传入（模型对线框图理解有限，需文字补充尺寸）
│   └─ SD/ComfyUI → 路线 C：ControlNet 约束，可做到"墙就是那堵墙"
└─ 有喜欢的参考效果图
    └─ 路线 B：参考图锁风格与构图 + 文字改细节（换色、换材质、换家具）
```

**推荐组合**：内置/在线工具快速出多方案 → 用户选定方向后 → SD/ControlNet 出贴合户型的定稿 → 关键空间再精修放大。

## 二、读图方法

### 1. 户型图（JPG/PNG）

直接读图，识别：房间数量与形状、门窗位置、朝向（多数图上北下南，以指北针为准）、标注尺寸、承重墙（填充为实心黑/深灰的墙体）。

**无标注尺寸时反推**：住宅常见开间 3.0-3.9m、进深 3.3-4.5m、室内门洞 0.8-0.9m、入户门 1.0m、窗台高 0.9m（落地窗除外）。反推值必须标注"估算"。

### 2. CAD（PDF/DWG）

```python
# CAD PDF 转高清 PNG 后读图（4x 渲染保证线条清晰）
import pymupdf  # fitz
doc = pymupdf.open("floorplan.pdf")
page = doc[0]
pix = page.get_pixmap(matrix=pymupdf.Matrix(4, 4))
pix.save("floorplan_4x.png")
```

**像素测距校准**（图纸有总面积标注时）：

```
线长比 = √(实际面积 ÷ 像素面积)
实际长度(m) = 图上像素长度 × 线长比
```

**承重墙识别**：深灰/黑色加粗实线或填充实体墙通常为承重结构，读图时单独列出，**并提醒用户：图纸判断不能替代结构核验，拆改前必须查物业结构图并请结构师确认**。

DWG 文件本机无 CAD 时可：① 让用户在 CAD 里导出 PDF/PNG；② 用 ODA File Converter / LibreCAD 转换；③ 用 `ezdxf` 读取图层与线段（适合有标注文本的标准图纸）。

### 3. 毛坯房照片（图生图底图质量决定成败）

**拍摄要求**：
- 站墙角拍，让**两面墙 + 地面 + 顶面**同时入镜（空间结构信息最全）。
- 镜头高度 1.4-1.6m，横平竖直（开网格线，竖线不要歪）。
- 白天拍、开所有灯，避免逆光与大面积过曝窗户。
- 每个空间至少 2 个角度；有梁、柱、管道必单独拍清楚。
- 清理地面杂物，但不能改变结构（不要移走已砌墙体、管道）。

**不要用的图**：广角畸变严重、光线昏暗、只拍到一面墙、带水印的图。

## 三、各平台参数速查

### Midjourney（画质天花板，需外网）

| 用途 | 参数 |
|------|------|
| 写实室内 | `--style raw --s 50-100 --v 7`（`--s` 越高越艺术化，写实取低值） |
| 画幅 | 客餐厅/横厅 `--ar 16:9`；卧室/厨卫 `--ar 4:3`；小红书竖版 `--ar 3:4` |
| 负面 | 用 `--no` 结尾列出，或用 `--no clutter, ornate moulding, text` |
| 风格一致性 | 用 `--sref <参考图URL>` 锁风格，跨空间统一 |

### 即梦 / 通义万相 / 文心一格 / 混元（国内直访，有免费额度）

- **中文提示词直读**，可直接用 `references/prompt-library.md` 中文模板。
- 选"写实 / 摄影"模型，精绘/高清选项开到最高。
- 支持图生图：上传毛坯照，强度（参考力度）取 **0.5-0.7**；太高会照抄毛坯、太低会脱离户型。
- 批量出方案性价比最高：同一提示词出 4 张挑构图。

### Stable Diffusion / Flux + ControlNet（户型贴合度最高）

| 控制类型 | 作用 | 适用场景 | 推荐权重 |
|----------|------|----------|----------|
| **Canny** | 锁边缘轮廓 | 有清晰线框户型图 | Control Weight 0.6-1.0 |
| **MLSD** | 检测直线（墙线、门洞） | 户型图/毛坯照，最常用 | 0.6-0.9 |
| **Depth** | 锁空间深度与进深 | **毛坯房照片首选**，保留空间感 | 0.7-1.0 |
| **Seg（语义分割）** | 按区域指定材质 | 需精确控制墙/地/柜分区 | 0.5-0.8 |

**通用参数**：

```
底模：写实室内 checkpoint / SDXL + 室内 LoRA
Denoising strength（重绘幅度）：0.6-0.8
  ├─ 0.4-0.5：几乎保留原图，只改风格（用于毛坯照微调）
  ├─ 0.6-0.7：平衡（推荐起点）
  └─ 0.8-1.0：大幅重构，户型约束会变弱
Steps：25-40，CFG Scale：6-9
采样器：DPM++ 2M Karras / Euler a
分辨率：768-1024 起步 → Hires.fix 或 4x 放大精修
```

**ControlNet 标准流程**：
1. 预处理参考图（Canny/MLSD/Depth 提取控制图）→ 检查控制图是否清晰表达墙体。
2. 主提示词 = 五部分公式；负面提示词 = 通用基线。
3. Control Weight 先取 0.7、Denoise 取 0.65 出第一版。
4. 结构不像 → 提高 Control Weight 或降 Denoise；风格不美 → 反之。

### 内置生图工具（ImageGen）

- 文生图与图生图均支持；图生图通过参考图参数传入（可传多张）。
- **参考图保真度**：高保真 = 结构贴但改动小；低保真 = 自由发挥但脱离户型。起点取中高保真。
- 画幅：竖图 1024×1536、横图 1536×1024、方图 1024×1024。
- **成本**：单张约消耗 5-10 点信用，**生成前必须告知用户张数与预计消耗**。
- 策略：先出 2-4 张抽卡定构图 → 选中一张 → 以该图为参考做定向修改（改色/换材质/换家具），比重新抽卡省成本。

## 四、抽卡与迭代策略

### 抽卡原则

1. **先定构图，再谈细节**：第一轮 2-4 张只用来选视角与布局，不要纠结材质。
2. **一次只改一类变量**：比例不对就只加尺寸词；配色不对就只改色板词。同时改多项无法定位有效词。
3. **定向修改优于重抽**：选中一张后，以它为参考图 + 局部改词（如"把柜体改为深灰哑光""去掉吊灯"），命中率高于重新抽。
4. **卡住就换工具**：同一提示词在 A 工具出不来效果，换 B 工具常常一次命中（尤其 MJ 氛围好、SD 结构准）。

### 常见调整指令对照

| 想改什么 | 加什么词 | 减/负面 |
|----------|----------|---------|
| 家具体量太大 | `{面积}㎡, human-scale furniture, 0.9m walkway` | `--no oversized furniture` |
| 空间显压抑 | `{层高}m ceiling, vertical proportions, uncluttered` | `--no low ceiling` |
| 太冷/太暖 | 换灯光色温 `warm 3000K` / `neutral 4000K` | — |
| 点缀色太抢 | `accent only in soft furnishings, <10%` | `--no {accent} walls, no {accent} cabinets` |
| 太样板间 | `lived-in, books on shelf, plants, textile throw` | `--no empty showroom` |
| 塑料感 | `shot on 35mm, f/8, realistic material reflections, natural grain` | `--no CGI, no 3D render look, no plastic` |
| 家具畸形 | 重抽并降 CFG（6-7） | `--no distorted geometry, no extra legs` |
| 门窗乱加 | 明确写 `one {朝向} window, one doorway` | `--no extra doors or windows` |

## 五、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 图上出现乱码文字 | 模型倾向加字 | 负面词必带 `no text, no watermark, no logo` |
| 家具比例明显失真 | 提示词缺面积/尺寸 | 补 `X㎡ (长×宽), Xm ceiling` + `human-scale` |
| 墙面门窗数量对不上 | 无结构约束 | 改走 ControlNet（MLSD/Depth），或提高参考图权重 |
| 出图与参考图完全无关 | 重绘幅度过高 | 降 denoise 至 0.5-0.6，或提高参考图保真度 |
| 毛坯照几乎没变 | 重绘幅度过低 | 提 denoise 至 0.7-0.8 |
| 全屋一个风格但各图不统一 | 每图独立写词 | 统一锚点段 + 同一色板；MJ 用 `--sref` |
| 反复出不理想的那张 | 模型偏好 | 换工具/换底模，比死磕提示词快 |
| 深色系出图发黑 | 深色占比过高 | 基底提到明度 ≥60，深色仅 20% 主体 |
| 出图模糊 | 分辨率/精绘未开 | 开高清精绘 + Hires.fix 放大，再局部重绘细节 |

## 六、交付建议

1. **图纸与提示词一并交付**：用户拿到提示词可自行在其他平台复现。
2. **标注估算值**：尺寸为估算的必须写明，避免用户按图下单出错。
3. **效果图 ≠ 施工图**：出图后提醒用户，效果图仅供风格与比例参考，实际尺寸以现场复尺为准；涉及拆改的必须走结构核验。
4. **分空间打包**：每个空间一张事实卡 + 一套中英提示词 + 出图结果，命名规范 `空间_风格_版本.png`。
